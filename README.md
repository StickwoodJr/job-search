# AI Job Search Dashboard

Live Interactive Job Search & Co-op Application Tracker Dashboard.

🌐 **Live Dashboard**: [https://stickwoodjr.github.io/job-search/](https://stickwoodjr.github.io/job-search/)

### Features
- **Application Status**: Real-time tracking of active, interview, offer, and resolved applications.
- **Visual Analytics**: Dynamic SVG status doughnuts, sector breakdowns, application channel stats, and recruitment funnel progression.
- **Search & Filtering**: Multi-criteria client-side filtering by job board, status, company, and role.
